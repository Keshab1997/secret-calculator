# 🔐 Secret Calculator

A secret messaging app disguised as a calculator! 

## Features

### Calculator Mode (Default)
- Full calculator functionality
- Supports: +, -, ×, ÷, %, decimal
- Clean, modern UI

### Secret Chat Mode 🤫
Enter the secret code **`1997`** to unlock:

- 💬 **Text Messaging** - Send and receive messages
- 😊 **Emoji Support** - Full emoji picker with 32+ emojis
- 📸 **Image Sharing** - Share photos from gallery or camera
- 📞 **Voice Calls** - Call your special someone
- 📹 **Video Calls** - Face-to-face conversations
- 📱 **SMS Integration** - Send text messages

## How to Use

1. Open the app - it looks like a regular calculator
2. Type `1997` on the calculator
3. The secret chat screen will appear!
4. Chat, share images, make calls

## Technical Details

- **Framework**: Flutter 3.47.7
- **Language**: Dart
- **UI**: Material Design 3
- **Image Picker**: image_picker package

## Installation

```bash
# Clone the repository
git clone https://github.com/Keshab1997/secret-calculator.git

# Navigate to project
cd secret-calculator

# Install dependencies
flutter pub get

# Run the app
flutter run
```

## Building

```bash
# Android APK
flutter build apk

# Android App Bundle
flutter build aab

# iOS
flutter build ios
```

## Security Note

This app is designed for private conversations. The secret code provides an additional layer of privacy, but always ensure you're using secure networks for sensitive communications.
